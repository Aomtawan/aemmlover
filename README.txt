DORAEMON LOVE MISSION — เวอร์ชันเตรียมเผยแพร่ออนไลน์

โครงสร้างโฟลเดอร์:
- index.html
- style.css
- script.js
- music.mp3  <-- ต้องเพิ่มไฟล์เพลงที่คุณมีสิทธิ์ใช้งาน
- images/
  - photo1.jpg ถึง photo5.jpg (รูปหน้าแรกที่สลับวน)
  - photo6.jpg (รูปหน้าสำเร็จ)

ก่อนเผยแพร่:
1. สร้างโฟลเดอร์ images
2. ใส่รูป 6 รูป ตั้งชื่อตามรายการด้านบน (ตัวพิมพ์เล็กทั้งหมด)
3. ใส่ไฟล์เพลงที่ใช้ได้อย่างถูกลิขสิทธิ์ ชื่อ music.mp3 ไว้ข้าง index.html
4. ทดสอบเปิด index.html ด้วย Live Server
5. ตรวจสอบการแสดงผลบนมือถือ

เพิ่มเพลง:
- ปุ่ม “♫ เปิดเพลง” อยู่ด้านล่างซ้าย
- เบราว์เซอร์มือถือมักไม่อนุญาตให้เล่นเพลงอัตโนมัติ จึงต้องกดปุ่มเปิดเพลงเอง
- ห้ามนำเพลงเชิงพาณิชย์มาเผยแพร่โดยไม่มีสิทธิ์ ควรใช้เพลงที่แต่งเองหรือเพลงที่อนุญาตให้ใช้บนเว็บไซต์

วิธีเผยแพร่ฟรีด้วย Netlify Drop:
1. ไปที่ https://app.netlify.com/drop
2. สมัคร/เข้าสู่ระบบถ้าระบบร้องขอ
3. ลากโฟลเดอร์โปรเจกต์ที่มี index.html, style.css, script.js, music.mp3 และ images/ ไปวางในพื้นที่อัปโหลด
4. รอให้ Netlify เผยแพร่ แล้วคัดลอก URL ที่ลงท้ายด้วย netlify.app
5. เปิดลิงก์นั้นบนมือถือทดสอบ และส่งให้ผู้รับได้

สำคัญ:
- อย่าอัปโหลดเฉพาะ index.html ต้องอัปโหลดทั้งโฟลเดอร์และไฟล์ที่เกี่ยวข้อง
- ถ้าแก้เว็บภายหลัง ให้อัปโหลดโฟลเดอร์เวอร์ชันใหม่อีกครั้ง
- แผงแก้ไขข้อความในเว็บเป็นการทดลองแก้บนหน้าปัจจุบันเท่านั้น ไม่ได้บันทึกถาวรและไม่ได้ส่งข้อมูลกลับมาหาคุณ
- หากจะใช้รูปโดราเอมอนจากการ์ตูนหรือเพลงที่มีลิขสิทธิ์ ควรตรวจสอบสิทธิ์การใช้ โดยเฉพาะเมื่อเผยแพร่สาธารณะ
